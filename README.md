# NRW Maintenance Mode

A modern, lightweight and SEO-safe WordPress maintenance mode plugin with beautiful built-in themes, custom HTML support and live preview.

---

## ✨ Features

- SEO-safe maintenance mode
- Proper 503 status headers
- Noindex support
- 3 beautiful built-in themes
- Custom HTML maintenance page upload
- Live preview system
- Full page preview
- Admin bypass mode
- Minimal modern dashboard UI
- Lightweight and fast
- Mobile responsive
- Plugin-safe architecture
- Does not affect existing plugins or SEO
